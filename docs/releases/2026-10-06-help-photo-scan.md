# 帮助、拍照识别与简化首页

日期：2026-10-06，Asia/Bangkok。代码与本机检查已完成；本记录初稿尚未声明生产部署或真机验收。后续部署事实补记在本文。

## 行为

- 右上角 CMI Community 打开 `/help` 使用说明；`/community` 兼容地址也显示帮助。说明两种情况、国内运输单号、相机识别后手动查询、批量登记、联系方式与回执。
- 扫码默认“拍照识别”：相机取景后等待用户拍照，空闲不持续解码；固定一次原始画面，在本机有限次数尝试。未识别到时提示重拍，也可切换实时扫码。切换识别方式沿用相机，不再次请求权限；识别成功或关闭后停止轨道。
- 重复点击不排队，关闭、切换方式或相机取消旧任务，迟到结果不能填号。临时画面不上传、不持久保存；解码来源仍为 `barcode`，填号后手动点击查询。
- 首页删去用户指定的两句标语，收紧顶部留白；全界面及 favicon 移除包裹形状图标。
- 公众号标题为“关注 CMI 公众号”，群码上方标“微信群”。仅对已核对的群长截图使用 `(80,390,560,560)` 安全显示裁切，保留每侧40px白边；原图与社区配置不改，换图后默认完整显示。

## 已验证

- `RUN_SCOPED_POSTGRES_TEST=true npm run check` 通过：138项 Vitest（包含真实隔离 PostgreSQL 范围恢复），17项 Edge 测试，TypeScript/Deno 检查通过；`npm run build` 通过。
- 45项相机测试覆盖拍照等待、冻结像素真实ZXing解码、连点复用、失败不循环、模式与相机切换、迟到取消，以及成功回调关闭相机后仍返回成功。
- 浏览器本机合成视频使用真实ZXing：拍照前不填号；空白画面提示重拍；合成条码 `PDD404TEST000001` 拍照解码后填号、停止轨道，未自动查询。实时/拍照切换的相机申请次数保持1；手动关闭后轨道为 ended。
- 顶部入口实际打开帮助并可返回查询；360px首页无横向溢出，包裹图标数为0。生产公开社区素材只读用于核对，两张二维码完整加载；群码裁切后方形展示，完整码与白边可见。
- 本机截图保存在忽略的 `output/scanner/`，合成相机验证不代表物理摄像头清晰度或实际速度。
