## 实测与边界

一张虚构物流截图已通过真实签名上传、文件校验、扫描事务提交和持久任务。两次旧代码重试将 OpenAI 429 归类为限速；第三次使用修复明确得到 `OPENAI_CREDIT_EXHAUSTED` 并停止重试。已有一条失败的临时查询，正式记录为零。对应费用账本 spent/reserved 均为零；不能将真实上传成功写成识别或匹配成功。

匿名业务表与事务 RPC 拒绝访问，两个包裹图片 bucket 保持私有。社区入口图片使用单独公开 bucket，未增加匿名写入策略。云端公开注册已关闭，全局存储文件上限为 5MiB。每分钟定时补偿启用，实际 worker 唤醒返回 202；空队列不调用 OCR。前端加群声明不授予任何私密信息权限。

分页、版本选择与迟到响应的合成数据测试已通过；这些不能替代真实 OCR、双向匹配、管理员交还和真机验收。实际费用不足时不更换模型规避、不清零重试次数、不改预算；补足额度后用保存的虚构图片创建新输入版本再识别。
