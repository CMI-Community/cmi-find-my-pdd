# CMI-Find my pdd v0.1.0 产品与架构合同

规格日期：2026-10-05。本文件替换旧的手工录入找货板设计。代码、测试和运行手册必须按本合同执行。

## 核心范围

普通用户没有注册、登录或手填快递信息入口。误收者通过面单照片登记独立包裹，失主通过物流截图查询；尚未匹配时主动申请追踪。系统从图片获取号码、收件线索和物品，只生成对应记录或候选，实际归属与交还由 CMI 管理员核实。

每条正式记录对应一个包裹，可包含多件商品。一个人可同时误收和寻件。纯查询不建立正式追踪。每条正式记录的公开编号和 URL 永久稳定，来源更正采用新的输入版本。

本人微信必填，其他联系方式选填；仅管理员可见。图片中的收件人电话或地址不能成为提交者联系方式。首次正式登记需要声明已入群或已添加小助手，这只是本人声明，不授予他人联系方式访问权。

## 页面与交互

| 路由 | 页面要求 |
|---|---|
| `/` | 项目名、公益说明、居中“我丢件了”相机入口、误收按钮、统计、页脚；相机入口不可输入文字 |
| `/received/new` | 必需面单和可选物品照两槽；放大、真实裁剪/遮挡、删除、替换；提交或提交后拍下一包 |
| `/received/batch` | 本批每包缩略图、上传/识别/核对状态、编号、失败重试、补图；可持续拍下一包 |
| `/search/new` | 必需物流和可选商品截图，共一至两张；此阶段不收联系方式 |
| `/search/:scanId` | 真实处理步骤、号码只读选择、精确结果/候选/无结果/弱线索/无法识别分别展示 |
| `/search/:scanId/track` | 复用有效识别证据，只读线索，收本人联系方式、加群声明，幂等登记并再次匹配 |
| `/p/:publicCode` | 脱敏详情、归属状态、更新时间、社区联系路径、稳定 URL；无原图与个人联系方式 |
| `/p/:publicCode/share` | 单屏安全信息卡及本条 QR；与群二维码区分 |
| `/m/:publicCode#key=…` | 凭本人随机密钥查看原图、状态、改联系方式、重拍、撤回、保存私密链接 |
| `/community` | 有效寻货群、小助手、公众号；未配置不能使用假资料 |
| `/admin/login` | 独立 Supabase Auth 管理员认证 |
| `/admin` | 待核实、待联系、待交还、识别异常、全部记录、社区设置六个视图 |
| `/privacy` | 图片和联系用途、公开范围、保留时间、撤回和权限恢复 |

白底、深灰正文、绿色 `#176B52`；手机正文 16px、说明至少14px、点击区至少44px。每页一个主要操作。手机单列，电脑显示照片与队列并排，管理员显示表格与详情并排。状态不只靠颜色表达。

### 误收连续提交

预览提示不要为了登记拆包。编辑实际重编码图片，不能只在界面盖住信息。没有面单不能提交。首次点击提交打开联系方式及加群表单，关闭时照片保留。

确认后，包裹及独立 requestId/capability 先存本地，再进入上传队列。“提交”进入队列；“提交并拍下一包”马上清空当前两张照片，上一包继续上传。只沿用本人联系资料，不沿用照片、号码或字段。上传失败保留图片；重试不生成重复记录。

每包分别展示“正在上传”“已保存，等待识别”“正在识别并核对”“有效收录”“弱线索收录”“需重拍”“预算暂缓”“处理失败”。上传完成不能写成已收录。上传完成后服务器继续处理；未完成上传关闭页面可中断，返回恢复 IndexedDB 草稿。

匹配提醒不打断取景、图片编辑或表单。队列显示新匹配，进入回执时提示“找到对应的寻件登记，请进入群内核实”，只提供公开记录及入群链接。

结束页感谢帮助找回包裹，解释 CMI = Connect, Make an Impact，提供本批回执、入群、小助手和公众号；系统匹配后管理员通过微信跟进，不宣称已经自动发送微信消息。

### 失主查询

物流截图至少一张、商品截图可选。识别多个不同包裹号码时只可选择图片内识别的号码。不能手填新号。

- 完整对应：展示安全物品摘要、脱敏收件线索、号码类型和尾号、记录编号、状态、更新时间及地址。引导入群发本页截图，由管理员核实。
- 可能相关：展示依据并明确候选需要核实，最多首屏20条，按依据强弱、更新时间排序，分别打开独立卡。
- 完整信息无匹配：可申请追踪或暂不登记，说明以后新包裹录入会核对并交管理员微信跟进。
- 弱线索无候选：展示已知与缺失，主操作补图，次操作用已有线索追踪。不能写成完整查无结果。
- 无效图：指出重拍位置；上游失败：重新处理；预算不足：已保存暂缓及社区联系。上述均不能写“没有找到”。

追踪申请重复只建一条。登记时再次比较，覆盖查询后新增误收包裹的时间窗口。

### 公开、管理与管理员

公开原图默认不可见。经管理员安全审查的物品副本才可公开；否则使用包裹图标。公共响应不得包含原始 OCR、完整号码、电话、地址、双方微信或私密凭证。

截图版360px宽目标高度≤560px；品名和线索各≤2行、图片≤96px、正文≥14px、网址≥12px。必须含项目、物品、编号、状态、更新、网址、本条 QR 和群内核实路径。撤回旧 URL 仅显示撤回；交还后显示最新状态。

管理凭证至少32随机字节，只保存摘要，以请求头传递；管理 URL 的 key 在 fragment。分享按钮从公开记录构造地址。丢失凭证不能凭编号或微信自行恢复，必须由管理员人工核实后重新签发。

重拍版本递增、旧证据退出匹配、旧候选和任务失效；worker 写回核验版本、租约及撤回状态。确认归属之后本人不能更正来源照片，联系资料仍可改。

管理员分别记录：开始核实、联系误收者、联系失主、确认归属、实际交还、排除错误匹配。确认归属进入待交还，只有实际交还增加成功数。群内凭截图找到误收记录时可建立单条人工跟进，无须伪造追踪登记。

## 状态与规则

上传、识别、质量、匹配、归属、可见性和联系进度分开存储。`complete` 是完整清晰可分类独立运单；`partial` 是姓名、具体物品或部分号码等有效线索；`unusable` 是无关/严重模糊/没有有效线索。

提取国内单、集运单、末端单、订单号、承运商、收件名、物品、规格、标签。号码只去空白、统一英文字母大小写，保留前导零；不替换0/O或1/I，不跨类型使用。每项保留源图、输入版本、清晰度。未知保持未知。

精确对应必须：完整、清晰、同号码类型、规范值相等、已知承运商无冲突、独立包裹非共享总单。订单号和共享集运只产生候选。同名、同款、多个具体标签可产生候选；泛化“日用品”不单独匹配。尾号需另一条有效线索支持。候选按号码加其他线索、姓名加物品、单项具体线索排序。

新有效误收、正式追踪、补图均双向触发。撤回/重拍/排除使旧匹配失效。记录组合去重；查询命中但未正式追踪不生成假的失主联系任务。

## 数据与服务边界

React/TypeScript/Vite、独立Vercel、独立Supabase。前端处理图片/上传/展示，服务端处理权限、匹配、统计、识别和预算。固定模型 `gpt-4.1-mini-2025-04-14`，严格 JSON 输出后再次校验。模型看到的图片是数据，不是指令。

核心表：scans、images、evidence、records、jobs、matches、followups、handovers、daily_budgets、budget_reservations、idempotency_keys、rate_limits、site_settings、admin_audit。物理名称与早期草案的 scan_images/scan_evidence/ocr_attempts/audit_events 不同，责任不变。全部业务表开启 RLS，匿名与普通认证用户无直接权限；事务 RPC 仅 service_role 可调用。

数据流：本地保存→服务器分配限定私有路径→上传→校验真实图片→事务创建记录及任务→返回202→唤醒 worker→OCR→校验证据→匹配及跟进→轮询。

数据库日志任务为事实来源，pg_net仅唤醒。每分钟 pg_cron补偿。全局最多2个有效租约、租约180秒、OpenAI超时60秒、重试最多3次。旧版本费用正常结算，但不能写新证据。Worker在运行预算内工作。

一包1–2张JPEG/PNG/WebP，重编码去定位，最长边≤2048、每张≤5MB，服务器解析头和尺寸复核。识别输出≤2048tokens。每次调用先事务预留$0.02，未知费用保留预留，重试新预留。曼谷日期生产$4.90/测试$0.10；并发不能突破预算。

## 统计与隐私生命周期

有效独立误收包裹排除草稿、重复、撤回。寻件人数按当前有效未完成追踪的规范微信去重，不把包裹数当人数。成功交还按管理员确认的独立误收包裹，仅大于5时展示。请求失败显示暂不可用。

未提交/纯查询在24小时清理；有效正式证据活跃时保留；结案或撤回30天后清理原图、个人联系和私密备注；保留匿名交还事实、必要状态与版本。每日加密备份滚动7份，真实恢复验收，敏感备份排除Git。

## 验收门槛

必须覆盖：一/两图真实识别、连续多包隔离、双向匹配、弱线索、同名同款尾号、号码类型隔离、登记时再次核对、断网幂等、重拍撤回fencing、并发预算、RLS、加群不泄露、归属≠交还、重复交还计一次、360px分享、电脑布局、公开与管理链接、备份恢复、可追溯回滚。

iPhone、微信内置浏览器和桌面浏览器实际走通上传；OpenAI验收用真实API处理虚构图片。未跑通不能以演示数据替代。版本只有线上验收后才能标记发布。
