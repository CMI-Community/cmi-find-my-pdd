# v0.1.0 验收记录表

每项填写环境、代码SHA、日期、证据和通过/失败/待验。没有证据的项目保持待验。

| 场景 | 通过标准 |
|---|---|
| 单面单/面单+物品照 | 真实上传/识别，角色区分、独立编号、私密管理权 |
| 多包队列 | 不串照片/号码/凭证，刷新或断网恢复，不重复登记 |
| 双向匹配 | 先追踪后误收、先误收后查询、查询后正式登记均正确 |
| 弱线索与无效图 | 保留有效姓名/物品，无效图重拍，文案不冒充无匹配 |
| 类型与相似线索 | 跨类型/共享总单不能精确，同名同款尾号仅候选 |
| 版本与撤回 | 识别中重拍/撤回，旧lease不能写回或提醒 |
| 预算与并发 | 原子预留/未知费用/3次上限/最多2lease，不能超日预算 |
| 权限 | anon/auth业务表和原图拒绝；加群声明不解锁私人数据 |
| 管理员交还 | 联系/归属/交还分开，重复交还只计一次，群内单条跟进可用 |
| 公开卡 | 无微信/原面单/完整单号，360px单屏，扫码对应本条 |
| 私密链接 | key只在fragment/header；分享永远公开URL |
| 实际浏览器 | iPhone、微信、桌面实际拍摄/相册上传通过 |
| 清理 | query24h/结案30d，图/联系/备注删除，匿名统计保留 |
| 备份与回滚 | 加密备份真实独立库恢复，部署回滚身份可追溯 |

自动测试覆盖不能代替有效群资料、真实API OCR、真机浏览器与恢复演练。
