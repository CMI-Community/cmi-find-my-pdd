# CMI Community brand asset

`cmi-community-logo.jpg` is the artwork supplied by the project owner on 2026-10-06 for public display on PDD404. The original image is preserved. It is brand artwork, not code or a synthetic fixture covered by the project MIT license.

`home-detectives-*.webp` and `lookup-detective-*.webp` are original fictional illustrations generated with the built-in imagegen tool for this product. Their reference, prompts and conversion details are recorded in `docs/design/home-detectives.md` and `docs/design/recipient-lookup.md`. They contain no real parcel labels, contact information or community member photos.
